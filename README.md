Paluwagan System

Paluwagan System Features:

Login/Sign up – Users can create their own profile and upload their photo
Encrypted Username and Passwords – for security purposes username and passwords in backend was encrypted
Group Making System – Users can create their own group as owner
Join Group System – Users can join group by random code
Admin Approval System – Admin verifies new members and transaction
Flexible target budget – Owners can decide what budget group must post
Payment Notification – Send alerts to users when they need to pay
Group Dashboard – Members can see total contribution, remaining balance, and next payout schedule
Basic Group Chat - Members can send messages
Group List – List all groups active and finished (active will always be on top)
Search – Search groups
Group Status – Members can mark group as finished, active, closed, etc.
Scheduled and Balance Salary Security Access - Restrictions to those not paying weekly
Payout Scheduling – Set and view who receives the lump sum and when

Note: This website project doesn’t use real world money, instead, we will use simulation money and will make another page just for money process.
